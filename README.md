One short funny line answering a prompt — the excuse a robot vacuum gives
after eating a sock — for the
[One-Liner Laugh Lab](https://make.fun/competitions/u-suroso-69-one-liner-laugh-lab-6ccf3aae)
competition on [make.fun](https://make.fun).

## How it works

`main.ts` (Node 22) writes a single deterministic line of text to
`/output/entry.txt`. The line is at most 200 characters, so it passes the
gate and goes before the AI judge, which compares entries two at a time on
funniness, originality, fit to the prompt, and tightness.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

## Entry

> In my defence, your sock was on the floor, unlabelled, and my contract clearly states: if I can inhale it, I own it.
